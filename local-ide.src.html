Step 1: Save the File

Download this file and rename it exactly to local-ide.html.

Step 2: Install the Local HTML IDE Skill

Copy the canonical read-only IDE operator skill and save it into your StickShift installation directory as skills/local-html-ide.md.

Run 100% Standalone Offline

You do not need any hosting environment. Simply double-click the downloaded file in your local directory (opening it via the file:// protocol) or drag it into any web browser. The tool works fully offline without any server configurations.

Export Work

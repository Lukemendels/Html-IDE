StickShift Onboarding Panel

Cockpit installation standard

Client-Side I/O Compliance: All code compiling, rendering, and downloading occurs 100% locally on your machine. Absolutely zero network requests are made.
Step 1: Save the File

Download this file and rename it exactly to local-ide.html.

Step 2: Install the Companion Skill

Copy the companion skill markdown configuration and save it into your StickShift installation directory as skills/local-html-ide.md.

Step 3: Access via Cockpit

Your LLM agent can now open and control this workspace tool directly inside your StickShift environment.

Run 100% Standalone Offline

You do not need any hosting environment. Simply double-click the downloaded file in your local directory (opening it via the file:// protocol) or drag it into any web browser. The tool works fully offline without any server configurations.

Export Work

Write or modify your HTML/CSS/JavaScript inside the editor. Review it in the real-time preview canvas, and click Download Completed Tool to save the work directly as a single compiled HTML tool back to your computer.

Companion Skill Template

This markdown is embedded into every downloaded tool (when Embed StickShift is checked) and becomes that tool's companion skill. Edit it to teach your agent more than the basic HTML open call. Placeholders are filled per tool at download time: {{TOOL_TITLE}} {{TOOL_FILE}} {{SKILL_SLUG}}

Saved in this browser (localStorage) and applied to all future downloads. Any raw closing script tag in the template is auto-escaped on embed so it cannot break the exported file.
